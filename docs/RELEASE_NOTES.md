# Feather AI 2.0 — release notes

Offline, USB-first Windows diagnostics with a three-agent pixel-art lab.

## What is in this release

- Portable Windows x64 build (`FeatherAI.exe`), no installer required.
- Read-only Windows diagnostics across 11 checks.
- Lead → Scanner → Repair handoff driven entirely by workflow events.
- One predefined repair proposal behind **Review fix**, with approve/decline and
  single-use approval enforcement.
- HTML, TXT, and JSON reports plus an audit trail written beside the executable.
- Original pixel-art agents and lab generated by `scripts/generate-art.js`.

## Verify before running

1. Compare the downloaded zip with `SHA256SUMS.txt`.
2. Confirm the release commit matches the repository.
3. The build is unsigned. Windows SmartScreen may warn; verify the source before
   choosing **More info → Run anyway**.

## Known scope limits

- The CI acceptance run uses a runner-local folder as a removable-drive
  substitute; a physical USB stick is not attached to the runner.
- Findings depend on the machine. The test proves the real Windows adapter runs
  and reports measured pass/warn/fail/error/unavailable states.
- No repair beyond the small predefined catalog is possible.
- No network, API key, or local model is used at any point.

See `README.md`, `docs/QUICKSTART.md`, and `docs/TESTING.md` for details.
